# Riasis Verde

Landing page for Riasis Verde — landscaping & gardening (Honduras).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Demo images live in `lib/demo-images.ts` (Unsplash). Replace with client photos before production.
